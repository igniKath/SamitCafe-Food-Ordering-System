# SamitCafe-Food-Ordering-System
A Python Flask-based mini food ordering system for SamitCafe. Built for ELEC 4 – Python Programming (Term Project, Option E: Mini Food Ordering System).

Overview

Customers can browse the SamitCafe menu, add items with a quantity to their order, view line totals and the grand total, remove items, or clear the whole order. All computations (line totals, grand total, validation) are done in Python using Object-Oriented Programming. Flask handles the routes and Jinja2 renders the pages.
